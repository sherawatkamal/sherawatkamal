# 💫 About Me:
🔭 I'm currently working on an agentic GraphRAG pipeline as a Graduate Research Assistant at Virginia Tech. It turns Revit 3D building models into a knowledge graph, then enriches it with project PDFs: documents get parsed into markdown, embedded as vector chunks, and linked to graph nodes by an LLM agent, so the system can answer questions the original BIM schema never could.<br><br>👯 I'm looking to collaborate on agent reliability, interpretability, and production ML systems that actually ship<br><br>🤝 I'm looking for help with finding my next role: new grad ML / SWE positions starting early 2027 (MS Computer Engineering, Virginia Tech, Dec 2026)<br><br>🌱 I'm currently learning genomic data science and how AI agents can make sense of biological data<br>Ask me about predicting LLM agent failures from hidden states (under review at AAAI 2027).<br><br>⚡ Fun fact: I went from building spring design software to probing the "brains" of 72B parameter models. Turns out both are mostly about tension.
